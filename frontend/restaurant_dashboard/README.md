# Restaurant Dashboard

A Flutter-based dashboard for restaurant partners on the food delivery platform.

## Features (Planned)
- Menu Management
  - CSV Bulk Upload
  - Time-Based Items (Breakfast/Lunch/Dinner)
  - Modifier Groups (Required/Optional)
- Kitchen Display System (KDS)
  - Tablet-friendly order queue
  - Prep time estimator
  - Order modification approval
- Analytics
  - Sales reports (hourly/daily/weekly)
  - Popular items heatmap
  - Customer insights

## Getting Started

1. `cd frontend/restaurant_dashboard`
2. `flutter pub get`
3. `flutter run`

## Consistent UI
This dashboard matches the look and feel of the customer app for a seamless brand experience.
